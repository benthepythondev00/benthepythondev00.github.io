Key eligibility and filtering fields

  • remote_scope: worldwide, restricted (country, region, or time-zone limit), or unknown.
  • eligible_locations: normalized countries or regions named in the posting (e.g. ["United States", "Canada"], ["EMEA"]). Time-zone rules like "CET +/- 3 hours" map to Europe.
  • eligibility_evidence: verbatim quote from the job description that triggered the classification.
  • work_arrangement: remote or hybrid (use excludeHybrid: true to drop office-day requirements).
  • visa_sponsorship & visa_sponsorship_evidence: true, false, or null with the employer's quoted sentence.
  • salary_usd_yearly_min & salary_usd_yearly_max: annual USD normalization across hourly, monthly, and 16+ currencies when stated.
  • sources: every board URL where the same deduplicated company/title role appeared.

Honest limits

  • 20 jobs per synchronous API.market call: Each API.market request runs live (no stale cache) and caps output at 20 jobs so responses finish inside gateway timeouts. Narrow your query or make multiple targeted requests for larger pulls.
  • Pattern-based English parsing: Eligibility extraction reads English phrasing. Non-US city names without a country (for example "Berlin" alone on Arbeitnow) remain unknown, and unusual phrasing can be missed. Always inspect eligibility_evidence before automating applications.
  • Salary completeness: Missing salaries stay null. When a board omits currency or period, USD normalization stays null rather than guessing.
  • Unofficial aggregation: This API reads public board feeds and is not affiliated with or endorsed by the listed job boards.
