Facebook Posts Scraper API

Facebook Posts Scraper API returns structured JSON posts from public Facebook pages and profiles without a Facebook account, session cookies, or browser setup. Send a single POST request with one or more page URLs, handles, or numeric IDs and receive up to 20 posts per request, including post text, publication timestamp, total reactions and breakdown by type (like, love, care, haha, wow, sad, angry), comment count, share count, video views, image URLs, video URLs, and shared post metadata. Plans start with a free Basic tier (4 requests/month, hard-capped) and scale to Pro ($25/mo, 449 requests), Ultra ($75/mo, 1,348 requests), and Mega ($150/mo, 2,696 requests).

TikTok Profile Scraper API

TikTok Profile Scraper API enriches public TikTok usernames and profile URLs with exact follower counts, following counts, total likes, video totals, verification flags, bio links, business category, TikTok Shop seller status, and recent video play statistics in a single JSON array response. No TikTok login, cookies, or developer app approval is required. Paid plans return up to 5 profiles per request (free Basic returns up to 2 profiles per request across 10 free monthly calls). Paid tiers start at Pro ($25/mo, 4,340 requests), Ultra ($75/mo, 13,020 requests), and Mega ($150/mo, 26,041 requests).

Instagram Profile Scraper API

Instagram Profile Scraper API turns Instagram usernames, @handles, or profile URLs into structured JSON without an Instagram login, cookies, or Graph API OAuth flow. Each profile row returns exact follower and following counts, full name, biography, resolved bio_links destination URLs (not l.instagram.com redirects), verified and private flags, pronouns, profile picture URL, and linked threads_username. Paid plans process up to 5 profiles per request in 2 to 5 seconds (free Basic returns 2 profiles per request across 10 monthly calls). Paid plans are Pro ($25/mo, 7,812 requests), Ultra ($75/mo, 23,437 requests), and Mega ($150/mo, 46,875 requests).

Job Search API (Indeed, LinkedIn, Reed, ATS Boards)

Job Search API unifies job postings from Indeed, LinkedIn, Reed, Wellfound, Welcome to the Jungle, Greenhouse, Workday, and multi-ATS company career pages under a single RapidAPI subscription and key. Each source is a dedicated POST endpoint accepting a clean JSON search body and returning a JSON array of live job postings with title, company, location, salary when published, posting date, description, and direct apply URL. Plans start with a free Basic tier (50 requests/month, hard limit) and scale to Pro ($4.99/mo, 1,500 requests), Ultra ($29.99/mo, 10,471 requests), and Mega ($99.99/mo, 34,912 requests).
