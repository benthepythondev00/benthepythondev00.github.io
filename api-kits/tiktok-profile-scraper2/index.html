TikTok Profile Scraper API

What is the TikTok Profile Scraper API on RapidAPI? TikTok Profile Scraper API enriches public TikTok usernames and profile URLs with exact follower counts, following counts, total likes, video totals, verification flags, bio links, business category, TikTok Shop seller status, and recent video play statistics in a single JSON array response. No TikTok login, cookies, or developer app approval is required. Paid plans return up to 5 profiles per request (free Basic returns up to 2 profiles per request across 10 free monthly calls). Paid tiers start at Pro ($25/mo, 4,340 requests), Ultra ($75/mo, 13,020 requests), and Mega ($150/mo, 26,041 requests).

Unlike generic TikTok downloader APIs that return rounded follower counts (such as 1.9M) and omit creator vetting metrics, this API returns exact integer counts plus recent_avg_plays, recent_median_plays, posts_per_week, tiktok_shop_seller, and optional per-video engagement rates via includeVideoStats.

## Summary
TikTok Profile Scraper API enriches public TikTok usernames and profile URLs with exact follower counts, following counts, total likes, video totals, verification flags, bio links, business category, TikTok Shop seller status, and recent video play statistics in a single JSON array response. No TikTok login, cookies, or developer app approval is required. Paid plans return up to 5 profiles per request (free Basic returns up to 2 profiles per request across 10 free monthly calls). Paid tiers start at Pro ($25/mo, 4,340 requests), Ultra ($75/mo, 13,020 requests), and Mega ($150/mo, 26,041 requests).

## Request Body Fields (`POST /`)
- `profiles` (array): One to 10,000 usernames, @handles or canonical HTTPS profile URLs. Duplicate handles are looked up once. Video URLs and shortened share links are not accepted.
- `maxProfiles` (integer): Maximum unique profiles to look up after duplicate removal. A request returns 5 rows at most.
- `delayBetweenRequests` (integer): Delay in milliseconds between requests to avoid rate limiting. Recommended: 500-1000ms
- `includeRecentVideos` (boolean): Add the videos TikTok lists for the profile (pinned ones and the latest ten, with play counts, posting times and links), their average and median plays, the posting rate and the time of the last post. Costs nothing extra.
- `includeVideoStats` (boolean): Read the latest videos from TikTok's creator list instead of the embed list: each video then also has likes, comments, shares, music title and its engagement rate ((likes + comments + shares) / plays), and the row gets recent_avg_engagement_rate. Pinned videos stay first. One extra request per 15 videos; costs nothing extra per profile.
- `maxVideosPerProfile` (integer): How many of the latest videos get likes, comments and shares when the option above is on. 1 to 50.

curl --request POST \

Python (requests)
import os
import requests

url = "https://tiktok-profile-scraper2.p.rapidapi.com/"
payload = {
  "profiles": [
    "nasa"
  ],
  "maxProfiles": 3
}

    "Content-Type": "application/json",
    "x-rapidapi-host": "tiktok-profile-scraper2.p.rapidapi.com",

Questions & Answers

Can I look up multiple TikTok profiles in one request?

Yes. Pass an array of handles or profile URLs in profiles (for example ["nasa", "@mrbeast"]). Paid plans return up to 5 profiles per request; the free Basic plan returns up to 2 profiles per request.

Does it return exact follower counts or rounded numbers?

Exact integer totals for followers, following, likes, and video_count at the time of the lookup.

How do I get engagement rate and likes per video?

Set includeVideoStats to true in the JSON request body. The API returns recent_avg_engagement_rate plus per-video likes, comments, shares, and music_title at no extra cost.

Does it detect TikTok Shop sellers and business accounts?

Yes. Each profile row includes business_account, business_category, and tiktok_shop_seller booleans.

Paste the n8n HTTP Request template below into n8n with your x-rapidapi-key, or add the MCP tool snippet to Claude Desktop or Cursor.
