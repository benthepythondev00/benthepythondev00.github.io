## Request Body Fields (`POST /h520E7cikakFSzjAg/run-sync-get-dataset-items`)
- `queries` (array): What to search for: job titles, skills or company names. Each entry is searched in each location. Indeed's operators work: title:(data analyst) matches the job title only, company:Siemens one employer, quotes an exact phrase.
- `locations` (array): Cities, regions or postcodes in the chosen country, for example Austin, TX or Manchester or 10115 Berlin. Leave empty to search the whole country.
- `countryCode` (string): The Indeed country site to search. Pay is read in each country's own currency. Links bring their own country.
- `maxResults` (integer): Rows to save for each search (each combination of keyword, location and job type) and each search link. A request returns 20 rows at most.
- `postedWithinDays` (integer): Keeps jobs Indeed listed within this many days. Any number works, and it works together with the job type and remote filters.
- `jobTypes` (array): Keeps jobs Indeed marks with this type. Several types are searched one after the other, and a job that carries two of them is saved once.
- `remote` (string): Keeps jobs Indeed marks as remote or as hybrid work.
- `titleOnly` (boolean): Indeed also matches words in the description, which brings jobs with unrelated titles. With this on, every search word must be in the job title.
- `distance` (integer): Miles in the United States and the United Kingdom, kilometres elsewhere. Without a value the distance is 25.
- `sort` (string): Newest first is the order for date limits and monitoring. Most relevant first is Indeed's own ranking for the first 1,000 jobs of a search.
- `links` (array): Search links from any Indeed country site (the words, place, age, distance, job type and remote filter of the link are used) and links of single jobs, which are looked up directly.

Questions & Answers

Which job boards are included under one subscription?

One RapidAPI subscription covers Indeed, LinkedIn, Reed, Wellfound, Welcome to the Jungle, Greenhouse, Workday, and ATS Career Pages.

How many job postings does one request return?

Up to 20 postings per request on Indeed, Reed, Wellfound, Greenhouse, Workday, and ATS Career Pages; up to 13 on Welcome to the Jungle; and up to 3 on LinkedIn.

Do I need separate API keys for each job board?

No. Every endpoint uses the same x-rapidapi-key and x-rapidapi-host (job-search-api-indeed-linkedin-reed-seek-and-ats-boards.p.rapidapi.com).

What does the Job Search API cost on RapidAPI?

Basic is $0/month (50 requests, hard-capped). Pro is $4.99/month (1,500 requests), Ultra is $29.99/month (10,471 requests), and Mega is $99.99/month (34,912 requests).
