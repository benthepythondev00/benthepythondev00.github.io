Instagram Profile Scraper API

What is the Instagram Profile Scraper API on RapidAPI? Instagram Profile Scraper API turns Instagram usernames, @handles, or profile URLs into structured JSON without an Instagram login, cookies, or Graph API OAuth flow. Each profile row returns exact follower and following counts, full name, biography, resolved bio_links destination URLs (not l.instagram.com redirects), verified and private flags, pronouns, profile picture URL, and linked threads_username. Paid plans process up to 5 profiles per request in 2 to 5 seconds (free Basic returns 2 profiles per request across 10 monthly calls). Paid plans are Pro ($25/mo, 7,812 requests), Ultra ($75/mo, 23,437 requests), and Mega ($150/mo, 46,875 requests).

Unlike Instagram scrapers that return wrapped l.instagram.com redirect URLs or fail the entire batch when one handle is missing, this API resolves every bio_links destination URL cleanly and skips missing handles without spoiling the rest of the batch.

## Request Body Fields (`POST /`)

Python (requests)
import os
import requests

url = "https://instagram-profile-scraper10.p.rapidapi.com/"
payload = {
  "usernames": [
    "natgeo",
    "nasa"
  ]
}
headers = {
    "Content-Type": "application/json",
    "x-rapidapi-host": "instagram-profile-scraper10.p.rapidapi.com",
    "x-rapidapi-key": os.environ["RAPIDAPI_KEY"],
}
response = requests.post(url, json=payload, headers=headers, timeout=120)
response.raise_for_status()
rows = response.json()
print(f'Returned {len(rows)} rows', rows[0] if rows else None)

Questions & Answers

Do I need Instagram cookies or a Meta developer app?

No. Requests run with no Instagram login or cookies. Authenticate only with your RapidAPI x-rapidapi-key header.

Does bio_links return real URLs instead of l.instagram.com redirects?

Yes. Every link in bio_links is unwrapped to its real destination URL (company websites, Linktree pages, etc.).

What happens if one username in my batch does not exist or is private?

Missing or hidden accounts are skipped without failing the request; the other valid handles still return. Private accounts return their public metadata with is_private: true.

How fast is a typical request?

Measured across 91 live subscriber requests, responses completed in 2 to 5 seconds with a 100% row return rate.

Does it return email addresses or post counts?

No. Instagram hides emails, phone numbers, and exact post counts from logged-out visitors, so those fields are omitted rather than guessed.
