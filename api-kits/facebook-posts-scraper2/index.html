Facebook Posts Scraper API

What is the Facebook Posts Scraper API on RapidAPI? Facebook Posts Scraper API returns structured JSON posts from public Facebook pages and profiles without a Facebook account, session cookies, or browser setup. Send a single POST request with one or more page URLs, handles, or numeric IDs and receive up to 20 posts per request, including post text, publication timestamp, total reactions and breakdown by type (like, love, care, haha, wow, sad, angry), comment count, share count, video views, image URLs, video URLs, and shared post metadata. Plans start with a free Basic tier (4 requests/month, hard-capped) and scale to Pro ($25/mo, 449 requests), Ultra ($75/mo, 1,348 requests), and Mega ($150/mo, 2,696 requests).

Unlike multi-endpoint Facebook suites such as Facebook Pages Scraper ($49/mo Pro) or Facebook Scraper API that split posts, reactions, and media across separate calls, this endpoint returns full post text, reaction breakdowns, video views, and media URLs in one POST call with built-in postedAfter and postedBefore date filters at no extra charge.

## Summary
Facebook Posts Scraper API returns structured JSON posts from public Facebook pages and profiles without a Facebook account, session cookies, or browser setup. Send a single POST request with one or more page URLs, handles, or numeric IDs and receive up to 20 posts per request, including post text, publication timestamp, total reactions and breakdown by type (like, love, care, haha, wow, sad, angry), comment count, share count, video views, image URLs, video URLs, and shared post metadata. Plans start with a free Basic tier (4 requests/month, hard-capped) and scale to Pro ($25/mo, 449 requests), Ultra ($75/mo, 1,348 requests), and Mega ($150/mo, 2,696 requests).

## Request Body Fields (`POST /`)
- `pages` (array): Links of public pages or profiles (https://www.facebook.com/NASA), their names (NASA) or numeric ids. Several pages are read side by side. A page that Facebook shows only to logged-in users (age or country limits) is reported and costs nothing.
- `maxResults` (integer): Posts to save for each page, newest first. A request returns 20 rows at most.
- `postedAfter` (string): Lower date limit: a day (YYYY-MM-DD) or a period back from now such as 3 days, 2 weeks or 6 months.
- `postedBefore` (string): Upper date limit: a day (YYYY-MM-DD, included) or a period back from now. The read starts at that day instead of paging down to it, so a month from two years ago costs only that month.

## Example Request (cURL)
```bash
curl --request POST \
  --url 'https://facebook-posts-scraper2.p.rapidapi.com/' \
  --header 'Content-Type: application/json' \
  --header 'x-rapidapi-host: facebook-posts-scraper2.p.rapidapi.com' \
  --header 'x-rapidapi-key: YOUR_RAPIDAPI_KEY' \
  --data '{"pages": ["https://www.facebook.com/NASA"]}'
```

Quickstart: cURL, Python & Node.js

Endpoint: POST https://facebook-posts-scraper2.p.rapidapi.com/

cURL
curl --request POST \
  --url 'https://facebook-posts-scraper2.p.rapidapi.com/' \
  --header 'Content-Type: application/json' \
  --header 'x-rapidapi-host: facebook-posts-scraper2.p.rapidapi.com' \
  --header 'x-rapidapi-key: YOUR_RAPIDAPI_KEY' \
  --data '{"pages": ["https://www.facebook.com/NASA"]}'
Python (requests)
import os
import requests

url = "https://facebook-posts-scraper2.p.rapidapi.com/"
payload = {
  "pages": [
    "https://www.facebook.com/NASA"
  ]
}
headers = {
    "Content-Type": "application/json",
    "x-rapidapi-host": "facebook-posts-scraper2.p.rapidapi.com",
    "x-rapidapi-key": os.environ["RAPIDAPI_KEY"],
}
response = requests.post(url, json=payload, headers=headers, timeout=120)
response.raise_for_status()
rows = response.json()
print(f'Returned {len(rows)} rows', rows[0] if rows else None)
Node.js (fetch)
const url = "https://facebook-posts-scraper2.p.rapidapi.com/";
const response = await fetch(url, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-rapidapi-host": "facebook-posts-scraper2.p.rapidapi.com",
    "x-rapidapi-key": process.env.RAPIDAPI_KEY,
  },
  body: JSON.stringify({"pages": ["https://www.facebook.com/NASA"]}),
});
if (!response.ok) throw new Error(`HTTP ${response.status}: ${await response.text()}`);
const rows = await response.json();
console.log(rows.length, rows[0]);

Questions & Answers

Do I need a Facebook login, cookies, or OAuth app review?

No. The API reads public Facebook pages and profiles as a logged-out visitor. You only send your RapidAPI key in the x-rapidapi-key header.

How many Facebook posts does one API request return?

Up to 20 posts per request, newest first. Use postedAfter and postedBefore (YYYY-MM-DD or relative periods like '7 days') to slice a specific date window.

Does it return reactions by type and video views?

Yes. Every post object includes total reactions, reactionCounts (like, love, care, haha, wow, sad, angry), comments, shares, videoViews, imageUrls, and videoUrl.

How do I connect Facebook Posts Scraper to n8n or Claude/Cursor?

Import the 1-click n8n HTTP Request workflow JSON below into n8n and paste your RapidAPI key, or register the MCP tool definition / Apify MCP server URL in Claude Desktop or Cursor.

What does Facebook Posts Scraper cost on RapidAPI?

Basic is $0/month (4 requests, hard limit so you never get surprise overages). Paid tiers are Pro at $25/month (449 requests), Ultra at $75/month (1,348 requests), and Mega at $150/month (2,696 requests).
