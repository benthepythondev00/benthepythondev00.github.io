How to get TikTok profile data: followers, likes, bios and recent videos

7 Nov 2026 · benthepythondev

If you already have a list of TikTok accounts and want their public stats in a spreadsheet, the TikTok Profile Scraper does that job. You give it usernames or profile URLs. It returns one row per account with exact follower and like totals, the bio, account flags and the account's latest videos with play counts. Results export as JSON, CSV or Excel. You don't need a TikTok login or a developer key.

What you get

Each profile row contains:

  • Identity: username, user_id, nickname and sec_uid.
  • Public totals: followers, following, likes and video_count. These are exact numbers. TikTok's own page shows something like "1.9M", but the row gives the full count.
  • Profile details: bio, bio_link and avatar_url.
  • Account flags: verified, private_account, business_account, business_category and tiktok_shop_seller.
  • Metadata: region, language and created_at. These can be null when the source has no value.
  • Recent videos: a recent_videos list. Pinned videos come first, then the latest ten. Each video has id, url, description, plays, posted_at, pinned, cover_url and video_url.
  • Summary figures: recent_avg_plays, recent_median_plays, posts_per_week and last_post_at. Pinned videos are left out of the averages, so one old viral clip doesn't skew them.
  • Lookup status: input_url and scraped_at.

Turn on includeVideoStats and each of the latest videos (1 to 50 of them) also gets likes, comments, shares, music_title and its own engagement_rate. The profile row then gets a recent_avg_engagement_rate as well.

What people use it for

These come straight from what the tool is built to do:

  1. Enriching a list of creators you already know. Paste in handles from a spreadsheet or CRM and get follower counts, verification status and bio links back for each one.
  2. Tracking growth over time. The scraper doesn't store history. Instead, you save the run as an Apify Task, schedule it, and compare each new snapshot with the previous one by user_id.
  3. Checking whether an account is a business or a shop. business_account, business_category and tiktok_shop_seller show whether an account is registered as a business, which category it picked (for example Clothing & Accessories) and whether it sells through TikTok Shop.
  4. Comparing recent performance. Median plays, posting rate and (with includeVideoStats) engagement rate let you see how active an account is right now, not just how big it is.

How to run it on Apify

Open the actor page on Apify. Paste this into the JSON input and start the run:

{"profiles": ["nasa"], "maxProfiles": 1, "delayBetweenRequests": 500}

When it finishes, go to Dataset → Export and choose your format. For a batch, list several entries in profiles. Plain usernames (nasa), handles with an @ (@mrbeast) and full profile URLs (https://www.tiktok.com/@nasa) all work, and case doesn't matter. Duplicate handles are only looked up once.

Honest limits

  • It only works on accounts you name. It can't find creators by topic, list an account's followers, download videos or give you past follower counts. For a short public history of daily counts, see the SocialBlade creator stats guide.
  • Large play counts are rounded. Plays come from the list TikTok publishes for embedding a profile, so big numbers show up as values like 425300 or 1500000. Small counts are exact.
  • Per-video likes, comments and shares need includeVideoStats. Turning it on adds one extra request per 15 videos. It costs nothing extra.
  • Media links expire. video_url and cover_url stop working after a few hours. avatar_url can expire too, so download anything you want to keep right away.
  • Private accounts have no video list. Their private_account flag doesn't give you access to private content.
  • Short links are skipped. Shortened share links and video URLs are reported in ERRORS. Use the account's normal profile URL instead.
  • Numbers change constantly. The same NASA profile showed 1,940,958 followers on October 3 and 1,989,721 on October 7, 2026. Every row is a snapshot from the moment of the run.
