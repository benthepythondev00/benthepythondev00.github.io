How to Get Pinterest Search Data: Pins, Creators, Boards and Rank

20 Nov 2026 · benthepythondev

You can type a keyword into Pinterest and scroll through the results. The hard part is getting those results into a spreadsheet you can use: titles, images, who posted each pin, which board it sits on, and where it ranked. Pinterest Search Scraper does that. You give it one or more search phrases, and it returns one row per public pin, in the order Pinterest showed them.

What you get

Each row is one public pin found for one search query. These are the fields:

  • Pin identity: id and url, the pin's Pinterest link.
  • Content: title and description, the text the creator wrote.
  • Image: image_url plus image_width and image_height. This is the best available version of the image.
  • Outbound link: destination_url and domain, the site the pin points to, if it points anywhere.
  • Dates and engagement: created_at, repin_count (save count) and reaction_counts.
  • Creator: pinner_id, pinner_username, pinner_name, pinner_followers and pinner_profile_url.
  • Board: board_id, board_name and board_url, when Pinterest shows them.
  • Search context: search_query, rank (the pin's position for that query) and scraped_at.

Pins are deduplicated within each query. You can download the results as JSON, CSV, Excel, XML or RSS, send them to a webhook, pass them to Make or Zapier, or read them through the Apify API.

Use cases

Pinterest SEO and ranking monitoring. Run the same keyword list every day or every week, then compare rank, id and url between runs. This shows which pins stay visible, which creators enter the results, and whether a campaign is gaining or losing search exposure.

Product and visual trend research. Search product categories, styles, seasonal phrases, materials or colors. Then look for themes that keep coming up in the titles, descriptions, images, boards and save counts before you plan a campaign or a product collection.

Creator and competitor discovery. Group rows by pinner_username, compare follower counts, and find the creators who rank for a topic again and again. This helps with manual partnership research. A profile showing up in the results does not make that creator a qualified lead.

Ecommerce destination analysis. Use destination_url and domain to see which sites get Pinterest traffic for a query. These can include marketplaces, publisher pages, brand stores and product collections.

  • queries: a list of search phrases. The default is web scraping.
  • maxResultsPerQuery: the most unique pins returned per query. The default is 10 and the maximum is 1,000.
  • maxPagesPerQuery: the most result pages requested per query. The default is 2 and the maximum is 50.

Start with a small limit when you test a new keyword set. Raise it only after the first output shows the query returns useful pins. To track changes over time, put the run on a schedule.

Honest limits

  • Public pins only. It collects what Pinterest search shows publicly. It does not log in or read private boards.
  • Fields can be null. Pinterest does not show every field for every pin. Organic pins, product pins, promoted content, older pins and different account types can carry different metadata. Missing values come back as null and are never made up. In the real rows above, repin_count is null on all three pins.
  • Uploaded pins have no outbound link. A pin uploaded directly to Pinterest shows destination_url: null and domain: "Uploaded by user". For destination analysis, filter these rows out.
  • Date format. created_at is a text date such as Mon, 09 Nov 2026 03:44:03 +0000. You will probably need to parse it before sorting or charting by date.
  • Bounded depth. Each query is capped at 1,000 results and 50 pages. The scraper can go past the first visible batch of results, but it will not return every pin ever made for a keyword.
  • Rank is a snapshot. rank is the order Pinterest returned at the time shown in scraped_at. Results can change between runs.
  • Results can be narrow. In the example run, the top three pins for web scraping all came from one creator with 4 followers. Check your sample before you draw conclusions about a whole niche.
