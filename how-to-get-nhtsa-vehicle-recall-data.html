How to get NHTSA vehicle recall data by make, model, year or VIN

24 Nov 2026 · benthepythondev

The US National Highway Traffic Safety Administration (NHTSA) publishes safety recalls and consumer complaints through free public APIs. The Vehicle Recalls Intelligence actor on Apify queries those APIs and returns each recall as one flat record. You can export the records as JSON, CSV or Excel.

This page shows which fields you get, what a real result looks like, and how to run it.

What you get

The actor has five modes: recalls, complaints, by_vin, by_campaign and list_makes.

In recalls mode (and in the VIN and campaign lookups), each record contains:

  • campaign_number: NHTSA's recall campaign ID, for example 23V070000
  • nhtsa_action_number: a related NHTSA action number, when one exists
  • manufacturer, make, model, model_year: the vehicle the recall covers
  • report_received_date: the date NHTSA received the recall report
  • component: the affected system, such as AIR BAGS:FRONTAL
  • summary: what the defect is
  • consequence: what can happen because of the defect
  • remedy: what the dealer will do, plus owner letter dates and the manufacturer's own recall number
  • notes: extra contact information, usually the NHTSA hotline
  • park_it: true when NHTSA advises owners not to drive the vehicle until it is repaired
  • park_outside: true when owners should park away from structures because of fire risk
  • over_the_air_update: true when the fix is a software update sent to the vehicle
  • scraped_at: when the record was fetched

Complaints mode returns different fields: odinumber, crash, fire, injuries, deaths, fail_date, date_of_incident, date_complaint_filed, vin, component and summary. List makes mode returns make_id and make_name for every make NHTSA tracks.

Use cases

These come from the actor's README:

  • Dealers and used-car sellers: check inventory for open recalls by VIN before listing or selling a car, and find the urgent "park it" cases that stop a sale.
  • Fleet and risk managers: watch for recalls across all the makes, models and years in a fleet, then send affected vehicles to the dealer for the remedy.
  • Car shoppers: read the recall history, defect summaries and warnings for a vehicle before buying it.
  • Researchers and legal tech: study defect trends, complaints, injuries and deaths across manufacturers, components and model years.

How to run it on Apify

  1. Open the actor page on Apify and click Try it.
  2. Pick a mode and fill in the fields that go with it:
    • recalls or complaints: makes, matching models, and optionally modelYear
    • by_vin: vins, a list of 17-character VINs
    • by_campaign: campaignNumbers, such as ["23V704000"]
    • list_makes: no extra fields
  3. Set maxResults (1 to 5000, default 100) to limit the size of the run.
  4. Run it, then view the dataset as a table or download it.

This input produced the example above:

{
  "mode": "recalls",
  "makes": ["Ford"],
  "models": ["F-150"],
  "modelYear": 2023,
  "maxResults": 100
}

You can also run it on a schedule, call it through the Apify API, or connect it to Make, Zapier or n8n. This actor is not listed on RapidAPI, so Apify is the only place to run it.

Honest limits

  • US data only. Everything comes from NHTSA, so recalls issued by other countries' regulators are not included.
  • Text fields are copied as they are. Summaries, consequences and remedies come straight from NHTSA, typos included (one example above says "increasng").
  • The date format needs care. In the example, report_received_date is a day/month/year string (10/02/2023), not an ISO date. Parse it explicitly before you sort or compare dates.
  • Model year is a string. model_year comes back as "2023", not a number.
  • Some fields are often empty. nhtsa_action_number was null in all three example records.
  • One recall can cover several vehicles. A record lists the model you searched for, but the summary may name other models covered by the same campaign. If you search several models, expect the same campaign number to show up more than once.
  • Mode decides the fields. Recalls, complaints and make lists have different columns, so keep them in separate datasets.
  • This is a lookup, not a repair status check. You get what NHTSA has published about a recall, not whether a particular dealer has fixed a particular car.
