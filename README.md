# benthepythondev00.github.io

Auto-synced searchable catalog of public [Apify](https://apify.com/benthepythondev) Actors (memo23-style).

- Feed: `data/actors.json` (generated by `scripts/sync_catalog.py`)
- Site: `index.html` (static, client-side search/filter)
- Dump money page: `reddit-rag-dump.html` (crawlable; organic inbound only)
- Quote hub: `custom.html`
- SocialBlade MCP FAQ: `socialblade-mcp.html` (source: api-selling `docs/socialblade-mcp/index.html`)
- Reddit history by date range (options table + curl): `reddit-historical-data-by-date-range.html`
- Zumper rental data tutorial: `how-to-get-zumper-rental-listing-data.html`
- Craigslist real estate data tutorial: `how-to-get-craigslist-real-estate-listings-data.html`
- Website tech stack and email provider tutorial: `how-to-get-website-tech-stack-data.html`
- Google Play reviews tutorial: `how-to-get-google-play-reviews-data.html`
- Austin rental-monitoring case study: `austin-rental-monitoring.html`
- Sanitized case-study sample: `data/austin-rental-monitor-sample-2026-08-20.json`
- Germany jobs for foreign skilled workers: `jobs-in-germany/` (built daily by `scripts/build_germany_jobs.py` from `jobs-in-germany/template.html`; tests: `python -m unittest discover -s tests`, `npx playwright test`)
- Denmark Fast-Track jobs: `jobs-in-denmark/` (built daily by `scripts/build_denmark_jobs.py` from `jobs-in-denmark/template.html`; SIRI certified companies mapped to public job boards in `data/denmark-ats.json`)
- `sitemap.xml` + `robots.txt`
- CI: hourly GitHub Action + manual dispatch

## Local sync

```bash
pip install httpx
# uses ~/.apify/auth.json or APIFY_TOKEN
python scripts/sync_catalog.py
python -m http.server 8080
```

## Secrets

Repo secret `APIFY_TOKEN` required for Actions.
