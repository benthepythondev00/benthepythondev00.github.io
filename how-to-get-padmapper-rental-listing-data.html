How to get PadMapper rental listing data

10 Nov 2026 · benthepythondev

To pull rental listings from PadMapper in a structured form, the PadMapper Rental Scraper does the work for you. You give it a city slug such as san-francisco-ca and a property type, and it returns one row per listing. It reads PadMapper's own JSON search API, so it doesn't run a browser and you don't need a login or an API key.

What you get

Each row describes one building or listing. These are the fields in a real run:

  • Identity and link: listing_id, url, name, plus source and a scraped_at timestamp
  • Location: full address, street, city, state, zipcode, neighborhood, and latitude / longitude
  • Price: price_min and price_max, the monthly rent range
  • Size: beds_min / beds_max (0 means studio) and baths_min / baths_max
  • Property details: property_type, an amenities list, and pets_allowed (for example dogs, cats)
  • Contact: phone, agent_name and brokerage_name, when the listing provides them
  • Terms: date_available and has_fees, a true/false flag for fees
  • Photos: image_ids and image_count, when includePhotos is on
  • Scoring: rating and lead_score, a 0 to 100 estimate built from rating, verification, amenities and price

What people use it for

The README lists these use cases:

  1. Real-estate lead generation. Build lists of rentals that have contact phones, then sort them by lead_score so the stronger leads come first.
  2. Rental market research. Compare prices, inventory and amenities across cities or neighborhoods. Coordinates and neighborhood names make it easy to group or map the rows.
  3. Price monitoring. Run the same search on a schedule and compare price_min / price_max between runs to catch rent changes.
  4. Automation. Send the listings to a CRM through Make, Zapier or n8n.

If you want a change-only feed instead of comparing runs yourself, the Zumper guide covers the same kind of rental data with a built-in monitor mode, and the Redfin guide covers a third source.

How to run it on Apify

Open the actor at apify.com/benthepythondev/padmapper-rental-scraper and set the input. The main fields:

  • locations: one or more city slugs, such as new-york-ny or toronto-on. Each city is searched separately using your filters. If you leave it empty, it searches san-francisco-ca.
  • propertyType: apartments, houses, condos, townhouses or rooms
  • minPrice / maxPrice and minBeds / maxBeds
  • maxListings: the cap per location. The default is 50 and the maximum is 10000.
  • maxPages: how many result pages to read per search, at 10 listings per page. The default is 20.
  • includePhotos: set this to get image IDs and a count

Example input:

{
  "locations": ["austin-tx", "denver-co"],
  "propertyType": "apartments",
  "minPrice": 1500,
  "maxPrice": 3000,
  "maxListings": 200
}

The scraper pages through results and removes duplicates along the way. You can export the results as JSON, CSV or Excel, schedule runs, or call the actor through the Apify API. You pay per listing returned, and there's no subscription.

Honest limits

  • Coverage is US and Canadian cities only. You pass a PadMapper city slug, not a free-text address or a radius.
  • Prices and bed counts are ranges for the whole building. A row with price_min 2840 and price_max 12400 covers several unit types, so it doesn't give you the price of one specific unit.
  • Many fields can be empty. In the sample run, rating and date_available were null on every row. Phone, agent and brokerage only show up when the listing includes them, and the agent is sometimes just the building name.
  • Photos come back as IDs, not image URLs. You get image_ids and a count. In this run, each listing returned 10 IDs.
  • The lead score is an estimate, calculated from the fields above. Treat it as a way to sort your list, not as a judgment of the property. With rating empty, the scores in the sample were all close together (46 to 50).
  • Page size limits how much you get. Each page holds 10 listings, so if maxPages is lower than maxListings divided by 10, you'll get fewer listings than maxListings.
  • Legal and contact rules still apply. The data comes from public listings, but you should respect PadMapper's terms. If you contact anyone, follow privacy and anti-spam laws such as GDPR and CAN-SPAM.
