How to get eBay listing data: prices, shipping, condition and seller ratings

14 Nov 2026 · benthepythondev

If you want to know what something sells for on eBay right now, a spreadsheet of live listings is the useful starting point. That means price, shipping, condition and some idea of whether each seller can be trusted. The eBay Scraper on Apify turns a keyword search into that dataset. It queries eBay's official Browse API, not the HTML pages, so there is no browser, proxy or captcha involved.

What you get

Each listing comes back as one row with these fields:

  • title: the listing title as the seller wrote it
  • price and currency: the price is a plain number and the currency sits in its own field
  • original_price and discount_percentage: filled only when the item is on sale, otherwise null
  • shipping_cost: the cheapest shipping option eBay offers for that item
  • condition: for example "New with box", "New without box", Pre-owned or Refurbished
  • seller_username, seller_feedback_pct and seller_feedback_score: who is selling and their feedback record
  • buying_options: fixed price or auction
  • category: the item's top category, such as "Athletic Shoes"
  • item_location_country: the country code where the item is located
  • item_id, url and image: the listing ID, a link to it, and a thumbnail
  • marketplace, search_query and scraped_at: which eBay site and keyword produced the row, and when it was collected

Use cases

The README lists these uses:

  • Price monitoring: run the same search on a schedule and track competitor prices or the market value of a product over time.
  • Reselling and arbitrage: look for underpriced items, spot discounted listings through original_price and discount_percentage, and check seller trends.
  • Market research: compare price spread, condition mix and seller reputation across the supported countries.
  • Product analytics: feed dashboards or repricing tools with current marketplace data.

How to run it on Apify

Open the eBay Scraper actor page and set the input:

  • searchQueries: one or more keywords. Each one is searched separately, and every row records its keyword in search_query.
  • marketplace: one of EBAY_US, EBAY_GB, EBAY_DE, EBAY_FR, EBAY_IT, EBAY_ES, EBAY_AU or EBAY_CA.
  • condition: all, new or used.
  • sort: best_match, price_asc, price_desc or newly_listed.
  • maxResults: the cap per search query, from 1 to 10000. The actor pages through results until it reaches the cap.

Example input:

{
  "searchQueries": ["nike air max", "iphone 15"],
  "marketplace": "EBAY_US",
  "condition": "all",
  "sort": "best_match",
  "maxResults": 100
}

You don't need an eBay developer account or API key. Results can be exported as JSON, CSV or Excel, and you can schedule runs, call the actor through the Apify API, or connect it to Make, Zapier or n8n. You pay per result, so a search that finds nothing costs nothing.

Honest limits

  • Keyword search only. The input is a search term plus filters. You can't give it a seller page or a list of item IDs.
  • Eight marketplaces. Only the US, UK, Germany, France, Italy, Spain, Australia and Canada sites are supported.
  • Active listings as the Browse API returns them. The README says nothing about sold or completed listings, so don't count on getting sold prices.
  • Shipping is the cheapest option. If an item ships at different prices to different places, you only see the lowest.
  • Discount fields are often empty. original_price and discount_percentage are null unless the item is on sale, as in all three rows from the real run.
  • Titles come through raw. The first example title ends with a tab and a space. Trim whitespace before you match or deduplicate.
  • Location is not always the marketplace country. On EBAY_US, the real rows included items located in GU and VI as well as US.
  • Some fields are strings. seller_feedback_pct comes back as text ("99.5"), and in the README sample so does discount_percentage. Convert them before doing any math.
  • Thumbnails are small. The image URLs in the real rows point to a 225 pixel version (s-l225.jpg).
