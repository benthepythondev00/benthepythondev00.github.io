How to get expired and deleted domain data from ExpiredDomains.net

24 Nov 2026 · benthepythondev

ExpiredDomains.net lists domains that have recently expired or been deleted. People use it to find aged names for SEO projects, to watch for drops, and to collect names for domain portfolios. The site shows this data in tables, and copying those tables into a spreadsheet by hand is slow. The Expired Domains Scraper reads a listing page and returns one clean row per domain, which you can filter, export or pass on to other tools.

What you get

Each row covers one domain from the listing you point the actor at:

  • domain and domain_tld: the name and its extension, for example com.
  • backlinks: the Majestic backlink count shown in the listing.
  • domain_pop: the domain-pop count shown in the listing.
  • archive_birth_year and archive_crawl_results: the year the domain first appeared on Archive.org and how many crawls it has there.
  • dmoz: the Dmoz field from the listing.
  • registered_tlds: how many related TLDs of the same name are registered.
  • related_domains: the related domain count.
  • dropped: the drop text the listing shows, such as "Yesterday 14:12".
  • whois_status: the Whois text from the listing, such as "Register now" or "registered".
  • tld_status: whether the same name is available or registered in .com, .net, .org and .de.
  • source_url and domain_search_url: the listing page the row came from and the ExpiredDomains.net page for that domain.
  • source: always expireddomains.net.

When the listing leaves a metric empty, the field comes back as null.

Use cases

From the README:

  • SEO domain research: find aged domains with backlinks and archive history.
  • Domain investing: watch deleted or expired names and export candidates.
  • Lead generation: spot domains that may need rebuild, brokerage, hosting or SEO services.
  • Competitive research: collect filtered domain lists and rank them in your own workflow.

How to run it on Apify

  1. Open the Expired Domains Scraper on Apify.
  2. Paste one or more ExpiredDomains.net listing URLs into urls, for example https://www.expireddomains.net/deleted-com-domains/.
  3. Set maxResults, the most domains you want per listing URL.
  4. Add filters if you want them. All are optional:
    • tlds: keep only certain extensions, such as com or io.
    • minBacklinks: a minimum backlink count.
    • minArchiveAgeYears: keep names first seen on Archive.org at least this many years ago.
    • maxLength: the longest name you want, not counting the TLD.
    • excludeHyphens and excludeNumbers: drop names with hyphens or digits.
    • maxPages: how many listing pages of 25 domains to read per URL.
  5. Start the run and export the results as JSON, CSV or Excel.

The input the Console starts with looks like this:

{
  "urls": ["https://www.expireddomains.net/deleted-com-domains/"],
  "maxResults": 20,
  "tlds": ["com"],
  "maxLength": 15
}

For SEO buying, the README suggests adding "minBacklinks": 10, "minArchiveAgeYears": 5, "excludeHyphens": true, "excludeNumbers": true.

Filters run inside the actor before a row is saved, so only matching domains end up in your dataset. You can also run it on a schedule, call it through the Apify API, or connect it to Make, Zapier or n8n.

This actor is not listed on RapidAPI. Use the Apify API if you want to call it from your own code.

Honest limits

  • It only sees the public listing. The actor reads the server-rendered table over plain HTTP with no login. Fields the listing leaves empty come back as null. In the real rows above, the Archive.org fields and dmoz were null for every domain.
  • Status fields are listing text, not a live check. dropped and whois_status are the strings the page shows, such as "Yesterday 14:12". Check availability with a registrar before you plan around a name.
  • Strict filters can return fewer rows. Without filters the actor reads one page per URL by default. With filters it reads up to 20 pages of 25 domains, and it stops there even if it has fewer matches than maxResults.
  • Failed pages are skipped. If a listing page fails, it is logged and skipped. Rows already saved stay saved, but that run may be missing that page's domains.
  • Metrics are a starting point. Backlink and domain-pop counts are the listing's numbers. A domain with many backlinks still needs a manual look at its history and link quality before you buy it.
