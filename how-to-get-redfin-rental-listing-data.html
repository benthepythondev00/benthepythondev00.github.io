How to get Redfin rental listing data

7 Nov 2026 · benthepythondev

If you need rent prices, unit sizes and amenities for apartments, houses, condos or townhomes listed for rent on Redfin, the Redfin Rental Scraper gives you each listing as one structured row. You choose a city and state, add filters if you want them, and get back rows you can export as JSON, CSV or Excel.

What you get

Every listing comes back as a single record. Based on a real run for San Francisco, CA, a row holds:

  • Rent: price as a number, price_text as shown on Redfin (for example $2,923 - $5,555/mo), plus rent_min and rent_max when a building has a range of units.
  • Unit size: bedrooms / bedrooms_max, bathrooms / bathrooms_max, sqft / sqft_max. A bedroom value of 0 means a studio.
  • Location: full address, split into street, city, state and zip_code, plus latitude and longitude.
  • Building details: property_type, available_units, a contact phone, a shortened description, and specials such as move-in offers.
  • Flags: income_restricted, senior_living and student_housing as true/false.
  • Amenities: unit_amenities (things inside the unit, such as a washer and dryer) and community_amenities (building features such as bicycle storage or on-site security).
  • Photos: photo_count, a main image_url and the full photos list.
  • Identifiers and metadata: rental_id, property_id, the Redfin url, listing_type, search_location, source, last_updated and scraped_at.

The README also describes a value score from 0 to 100 (value_score). It's built from price per bedroom, price per square foot, listing quality (photo count and amenities) and how complete the data is. A higher score means a stronger deal on those measures.

Use cases

These come straight from the actor's README:

  1. Apartment hunting. Filter by budget, beds, baths and pet policy, then sort by value score so the best-priced units come first.
  2. Rent benchmarking for property managers and landlords. Compare asking rents, amenities and square footage against similar units in the same city.
  3. Investor screening. Find rentals with a high value score as a starting point for buy-to-let and cash-flow analysis.
  4. Market research. Track rent levels and supply across neighborhoods and property types by running the same search on a schedule.

How to run it on Apify

Open the actor page on Apify and choose one of two modes:

  • search: set location (for example San Francisco, CA) and propertyType (apartments, houses, condos or townhomes). You can also set minPrice / maxPrice, minBeds / maxBeds, minBaths and petsAllowed (any, dogs, cats or both).
  • urls: paste specific Redfin rental links into listingUrls to get detail on exactly those properties.

maxListings caps the run (1 to 500, default 100). includePhotos and includeAmenities turn those parts on or off. Example input:

{
  "mode": "search",
  "location": "San Francisco, CA",
  "propertyType": "apartments",
  "minPrice": 1500,
  "maxPrice": 3500,
  "minBeds": 1,
  "petsAllowed": "dogs",
  "maxListings": 100
}

You don't need a Redfin login or API key. Results land in an Apify dataset that you can download, schedule, or connect to Make, Zapier or n8n.

Honest limits

  • Ranges, not single prices. For buildings with several units, price matches rent_min. Use rent_max, bedrooms_max and sqft_max if you need the top of the range. Some listings show Contact for Price instead of a number.
  • Descriptions are shortened in search results and end with "...". Use urls mode for fuller detail on specific listings.
  • Fields can differ by mode. The README mentions property_name, amenities_preview and a full amenities list depending on whether a search or detail page was read. Check your own output before you build a pipeline on a particular field.
  • 500 listings per run at most. For a large metro, split the work into several runs by property type or price band.
  • Public Redfin pages only. The scraper runs a real Chromium browser through Redfin's pages, so it's slower than a direct data feed. If Redfin changes its layout, fields can come back empty until the scraper is updated.
  • The value score is a heuristic. It weighs price, size, photos and completeness. It doesn't account for neighborhood, building condition or lease terms, so treat it as a way to sort listings and still review them yourself.
