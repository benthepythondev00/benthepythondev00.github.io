How to get transcripts of Instagram reels

16 Nov 2026 · benthepythondev

Instagram doesn't show subtitles to visitors who aren't logged in, so you can't copy a reel's spoken words from the page. The Instagram Reel Transcript Scraper on Apify does the listening for you. It works on public reels with no login and no cookies. It downloads the reel's separate audio-only stream and runs it through a Whisper speech model built into the Actor. No third-party speech service is involved, and you don't need an extra key.

If you want the captions, likes and media links of an account's posts instead of the spoken words, see How to get Instagram posts data from any public account.

There are two ways to feed it:

  • Reel links. Links to reels or video posts (/reel/, /p/, /tv/), or bare shortcodes. You get one row per link.
  • Usernames. Usernames, @handles or profile links. The Actor reads the newest reels of each account, up to your limit. Pinned reels are sorted by their real date, so old pinned reels don't push out this week's posts.

What you get

You get one row per reel. These are the fields:

  • Speech: transcript (the full text), segments (every spoken line with start and end in seconds plus its text), language, and languageProbability
  • Reel: shortCode, postUrl, caption, takenAt (when it was posted), durationSeconds, isPinned
  • Author: ownerUsername, ownerFullName, and handle (the account from your input the reel was found under)
  • Reach: likes, comments, plays
  • Files: thumbnailUrl, videoUrl, audioUrl
  • Outcome: status, plus statusReason when there's no transcript

If nobody speaks in a reel, the row tells you why. You won't get invented text.

Use cases

These come straight from what the Actor is built to do:

  • Turn an account's recent reels into text. Enter a username and maxReelsPerUsername, and you get the spoken words of the newest reels in a single run. You don't need a second Actor to find the reel links first.
  • Make subtitles or quote clips. Each segment has start and end times, so you can line text up with the video or jump to a specific sentence.
  • Compare what a reel says with how it did. Every row has the transcript next to its caption, posting date, likes, comments and plays.
  • Transcribe non-English accounts. Set language to a two-letter code such as de, es or pt. The README's example uses the German account tagesschau.

How to run it on Apify

Open the Actor page, fill in the input and start a run. These are the input fields:

FieldWhat it does
reelUrlsReel or post links, or shortcodes. For a carousel, the first video is transcribed
usernamesAccounts whose newest reels you want
maxReelsPerUsernameReels per account, default 3, up to 500. It doesn't apply to links
languageTwo-letter language code. Leave it empty to detect the language for each reel

You can fill both lists in the same run. Example:

{
  "usernames": ["ted", "https://www.instagram.com/bbcnews/"],
  "maxReelsPerUsername": 10
}

You can export results as JSON, CSV or Excel, put the run on a schedule, call it through the Apify API, or connect it to Make, Zapier or n8n. If you're switching from another transcript Actor, it also accepts the input names handles, maxReelsPerHandle, startUrls, bulkUrls, videoUrl and resultsLimit.

Honest limits

  • Public reels only. The Actor doesn't log in, so private accounts are out of reach.
  • Language detection can be wrong. It only listens to the first 30 seconds of speech. If a reel opens with music, noise or a second language, it may pick the wrong language and the text will be useless. In the author's tests, a news reel was detected as Swahili and came back as unclear_speech. With "language": "en" it gave a correct English transcript. If all the reels in a run share one language, set it.
  • It's machine transcription. Expect some misheard words. The example above contains the line "we're left with shallowness and avoid", which most likely should be "a void".
  • Carousels: only the first video is transcribed.
  • Usernames are capped at 500 reels each.
  • No speech, no text. Music-only or silent reels come back with a status and a reason, not a transcript.
